HOW TO RUN
----------
Database (Supabase SQL editor), in this order:
  1. TalkToJesus-backend/supabase-setup.sql
  2. TalkToJesus-backend/supabase-admin-setup.sql
  3. TalkToJesus-backend/admin-bootstrap.sql

Backend:
  cd TalkToJesus-backend && npm ci && npm run dev      # http://localhost:4040
  Admin console:                                        http://localhost:4040/admin

Mobile application:
  cd talktojesus-frontend && flutter pub get
  flutter run --dart-define=API_BASE_URL=http://localhost:4040

Tests:
  cd TalkToJesus-backend && npm test                    # 66 passing
  cd talktojesus-frontend && flutter test               # 75 passing

Full prerequisites, the complete environment-variable table and troubleshooting
are in 08-Installation-Guide.pdf (also Appendix B of the final report).
